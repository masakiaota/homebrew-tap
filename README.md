# masakiaota/homebrew-tap

Homebrew tap for [masakiaota](https://github.com/masakiaota)'s tools and apps.

## How to Install

### Formulae (CLI tools)

- **[junban](https://github.com/masakiaota/junban)** — Tool for managing compute jobs on a single machine:

  ```console
  $ brew install masakiaota/tap/junban
  ```

### Casks (macOS apps)

- **[Honyo](https://github.com/masakiaota/honyo)** — Local translation desktop app for macOS:

  ```console
  $ brew install --cask masakiaota/tap/honyo
  ```

- **[SmoothScroll](https://github.com/masakiaota/smooth-scroll)** — Smooth scrolling for mouse wheels and trackballs on macOS:

  ```console
  $ brew install --cask masakiaota/tap/smooth-scroll
  ```
